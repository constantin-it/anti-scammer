# 📋 План развития проекта AntiScammer (АнтиМошенник)

Проект: **Telegram-бот для защиты пользователей от кибермошенничества, социальной инженерии, фишинга и дропперства с использованием ИИ Google Gemini.**

---

## ✅ Что уже выполнено

### 1. Интеллектуальный анализ текста сообщений
- [x] Интеграция Google GenAI SDK (`google-genai`).
- [x] Строгая валидация структурированного вывода через Pydantic-модель `ScamAnalysisResult`.
- [x] Определение уровня риска (Низкий, Средний, Высокий, Критический), типа мошеннической схемы, списка тревожных признаков (red flags), юридических рисков и пошаговых рекомендаций.
- [x] Экспертный системный промпт с фокусом на дропперство, уголовную ответственность (ст. 205.1 УК РФ, ст. 174 УК РФ), поддельные ссылки и покупку игровой валюты.

### 2. Мультимодальный анализ скриншотов и изображений
- [x] Переход на актуальную модель **`gemini-3.8-flash`** (исправлена ошибка 404 устаревшей версии 2.5-flash).
- [x] Хэндлер для фото (`F.photo`) и несжатых файлов-картинок (`F.document`).
- [x] Передача изображения в виде байтов в Gemini для визуального OCR-анализа текста диалогов, фейковых чеков, реквизитов и QR-кодов.
- [x] Поддержка пользовательского комментария (`caption`) к скриншоту для обогащения контекста проверки.
- [x] Сохранение метаданных и ссылок на скриншоты в таблицу `screenshots` базы данных.

### 3. Мультимодальный анализ голосовых сообщений и видео
- [x] Обработка голосовых (`F.voice`), аудиофайлов (`F.audio`) и аудио-документов.
- [x] Автоматическая расшифровка (транскрибация) речи злоумышленников и вывод текста в отчёте (`transcription`).
- [x] Обработка видео (`F.video`), видеосообщений-кружочков (`F.video_note`) и видео-документов.
- [x] Анализ видеоряда (экраны телефонов, фиктивные платформы, признаки дипфейков) в поле `visual_details`.
- [x] Сохранение информации о медиафайлах в таблицу `media_logs`.
- [x] Защита от перегрузки (проверка лимита размера файла до 20 МБ).

### 4. Трекинг разоблачений и спасения пользователей
- [x] Создана таблица `scam_cases` в SQLite для учёта каждого раскрытого факта мошенничества (по тексту, фото, голосу и видео).
- [x] Автоматическая миграция предыдущих проверок из истории сообщений.
- [x] Интерактивная кнопка под вердиктом: **`🛡 Бот уберёг! Я не попался`** для подтверждения пользователем того, что бот спас его от перевода денег.
- [x] Динамический счётчик в приветствии `/start`:
  - Раскрыто мошенников и опасных схем;
  - Помог людям не попасться на обман;
  - Персональная статистика для конкретного пользователя.

### 5. Архитектура и безопасность проекта
- [x] Асинхронная база данных на `aiosqlite`.
- [x] Хранение истории переписки (`messages`) и профилей пользователей (`users`).
- [x] Middleware логирования сообщений с обработкой текста, аудио, видео и кружочков.
- [x] Безопасный `.gitignore` (исключены `.env`, `bot_database.db`, `venv`).
- [x] Создан файл [.env.example](.env.example).
- [x] Все ключевые фичи протестированы и закоммичены в локальный git-репозиторий.

## ⏳ Что предстоит сделать (Бэклог задач)

### 📌 Приоритет 1: Публикация и деплой
- [ ] **Запушить проект в GitHub**:
  - Выполнить `git push origin main` с персональным токеном доступа (PAT) GitHub.
- [ ] **Подготовка к непрерывной работе (Деплой 24/7)**:
  - Создать `Dockerfile` и `docker-compose.yml` для изолированного запуска.
  - Настройка systemd-сервиса на VPS/сервере для автоперезапуска бота при сбоях.

### 📌 Приоритет 2: Расширение каналов детекции
- [ ] **Парсинг и проверка ссылок**:
  - Проверка доменов на фишинг через базы Whois, Google Safe Browsing API или VirusTotal.
- [ ] **Детекция телефонных номеров и банковских карт**:
  - Проверка номеров телефонов и карт по открытым чёрным спискам и базам спама.

### 📌 Приоритет 3: Юзабилити и виральность
- [ ] **Работа в группах и чатах**:
  - Возможность добавить бота в групповой чат, чтобы он предупреждал участников о подозрительных ссылках или сборе денег.
- [ ] **Кнопка «Поделиться с другом»**:
  - Генерация ссылки на отчёт или пересылка памятки безопасности.
- [ ] **Административная панель / статистика**:
  - Команда `/admin` для просмотра графиков активности, частых схем обмана и количества спасённых средств.
