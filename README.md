# АнтиМошенник (AntiScammer) — Telegram-бот с ИИ-экспертизой безопасности

Интеллектуальный Telegram-бот для выявления мошенничества, манипуляций, фишинга, опасного дропперства и схем с нелегальными переводами (например, покупка игровой валюты по чужому номеру телефона, спонсирование экстремизма/терроризма).

---

## 🛠 Стек технологий
- **Python 3.12**
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram Bot API
- **Google GenAI SDK (`google-genai`)** — Google Gemini 2.5 Flash / 1.5 Flash со строгой валидацией схемы ответов (Structured Outputs через Pydantic)
- **pydantic & python-dotenv**

---

## 🚀 Быстрый старт

### 1. Создание и настройка `.env`
Создайте файл `.env` в корне проекта (скопировав из `.env.example`):
```bash
cp .env.example .env
```

Заполните его вашими ключами:
```env
BOT_TOKEN=123456789:ABCdef...        # Получить у @BotFather в Telegram
GEMINI_API_KEY=AIzaSy...              # Получить бесплатно на https://aistudio.google.com/
GEMINI_MODEL=gemini-2.5-flash        # Либо gemini-1.5-flash
```

### 2. Активация виртуального окружения
Виртуальное окружение уже создано в папке `venv/`:
```bash
source venv/bin/activate
```

*(Если ставите с нуля на новом сервере: `python3 -m venv venv && ./venv/bin/pip install -r requirements.txt`)*

### 3. Запуск бота
```bash
./venv/bin/python bot.py
```

## 💡 Функционал бота
1. **🔍 ИИ-экспертиза любого сообщения / переписки:**
   - Пользователь пересылает или вставляет текст предложения незнакомца.
   - Нейросеть мгновенно анализирует риск, выделяет тревожные флаги, юридические угрозы и пошаговые рекомендации.
2. **🚨 Защита от дропперства и экстремистских переводов:**
   - Предупреждение о статьях УК РФ (финансирование терроризма ст. 205.1 УК РФ, отмывание средств), когда мошенники просят перевести деньги «по номеру телефона физлицу».
3. **🎮 Схемы в играх (Robux, Brawl Stars, CS:GO, Telegram Stars):**
   - Разбор популярных детских и подростковых разводов на покупку доната.
4. **🆘 «Что делать, если уже перевёл?»:**
   - Четкий алгоритм действий (блокировка карт, обращение в банк, фиксация доказательств, заявление в полицию).
